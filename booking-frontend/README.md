# Saral Booking Frontend

Standalone Vite + React booking page for the Saral AI appointment/payment flow.

## Run

```bash
npm install
npm run dev
```

The page runs on:

```text
http://localhost:5174
```

A booking link generated by n8n looks like:

```text
http://localhost:5174/book/<booking-token>
```

Set:

```env
VITE_API_URL=http://127.0.0.1:8001/api/v1
```

The backend remains the source of truth for hospital, doctor, slot, fee and payment state.
